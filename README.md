# Mostly Old News

A scrollytelling data story: what the CFTC's Friday Traders in Financial Futures report says about asset managers' selling in equity index futures after an implied-volatility spike, 2006 to 2026.

**Read it:** https://lukegriscom.github.io/cftc-vol-story/ (add `?static=1` for the version without scrolling effects)

By Luke Griscom, Stevens Institute of Technology (FA 550, Assignment 5).

## What is here

- `index.html`, `style.css`, `story.js`: the page. Plain HTML, CSS and JavaScript with D3 v7 (`vendor/d3.min.js`, ISC license). No build step.
- `story_data.js` / `story_data.json`: every number the page draws, generated by `build/story_numbers.py`.
- `build/`: the script, the statistics module it reuses (`analysis.py`), and the weekly dataset it reads (`data/positioning_vol_weekly.csv`: CFTC positions joined to Cboe implied vol from FRED and weekly ETF returns from Yahoo Finance). `steelman_checks.py` tests the case for the volatility-targeting reading, using daily ETF closes (`data/etf_close_yahoo.csv`) for realized vol.

To regenerate the data: `cd build`, `pip install -r requirements.txt`, `python story_numbers.py`.

Not investment advice.
